# STV Election Shared Package

This package contains shared components, types, and utilities used by both the admin and voter applications.

## Contents

- **API Client**: Centralized API client for backend communication
- **Types**: TypeScript type definitions for all data models
- **Utils**: Shared utility functions

## Usage

```typescript
import { apiClient, Election, Position, Candidate } from '@stv-election/shared'
```

## Development

```bash
# Build the package
npm run build

# Watch for changes
npm run dev
```
